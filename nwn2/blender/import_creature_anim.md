# Blender Add-on for *Neverwinter Nights 2*

# Tutorial: Import creature animation

This tutorial uses Blender 3.3.1.

## Steps

1. Go to **File** > **Import** > **Neverwinter Nights 2 (.mdb/.gr2)**

   ![Import MDB/GR2](import.png)

2. Select the desired GR2 creature animation file from the file browser and
   click **Import MDB/GR2** or double click the file.

   **Tip**: You can select more than one file by holding `CTRL` while clicking.

   The import function will search for the GR2 skeletons referenced by the
   animation and import them too. If the import function can't find a skeleton
   or doesn't find the correct one, then you can manually copy the skeleton to
   the working directory and select both the animation and the skeleton files.
